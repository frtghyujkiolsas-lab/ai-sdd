# 06 前后端联调

## 联调目标

确认前端表单、后端接口、AI 证件照处理和工牌 PNG 输出在同一条链路中可以稳定跑通。

## 联调路径

```text
前端上传真实测试图
→ 调用 `/api/generate`
→ 后端处理照片和模板
→ 前端展示 `id_photo` 与 `badge_png`
→ 用户下载最终 PNG
```

## 测试用例

| 验收 ID | 场景 | 预期 |
| --- | --- | --- |
| AC-01 | 正常照片 + 完整字段 | 成功生成证件照和工牌 PNG |
| AC-04 | 缺少姓名 | 前端阻止提交或后端返回字段错误 |
| AC-04 | 未上传照片 | 返回照片必填提示 |
| AC-04 | 照片不清晰 | 返回处理失败提示 |
| AC-04 | HivisionIDPhotos 未启动 | 返回服务不可用提示 |
| AC-02 | 标准证件照检查 | 头像比例正常、背景统一、本人特征可辨识 |
| AC-03 | 工牌 PNG 检查 | 字段完整、模板不跑版、图片可下载 |

## 联调检查点

- 前端字段名与 API 契约一致。
- 后端返回字段与结果页读取字段一致。
- 生成结果可正常下载。
- 错误提示对非技术用户可理解。
- 本地构建和 Python 语法检查通过。
- 每个验收场景可回溯到 REQ-01 至 REQ-04，而不是只验证“接口有返回”。
